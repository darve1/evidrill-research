# 기술·오픈소스 경로

공식 문서, 버전별 릴리스, 원본 저장소의 관련 코드/설정, 유지관리자의 이슈 답변, 재현 가능한 벤치마크를 질문에 맞춰 읽는다. 업체 발표를 재인용한 문서 여러 개는 독립 실행 증거가 아니다.

- 조사 기준일과 commit/릴리스를 고정한다. 옛 문서의 지원 상태를 현재 버전으로 가져오지 않는다.
- README의 주장, 정적 코드 관찰, 합성 입력 테스트, 실제 입력 실행, 제품 환경 관찰을 분리한다. 설치하지 않았다면 런타임 성공을 주장하지 않는다.
- 실제 채택 판단에 필요한 플랫폼, 라이선스 대상, 모델/검색/API 의존성, 운영 비용과 실패 조건을 확인한다. 로컬 모델이 외부 검색/API까지 로컬이라는 뜻은 아니다.
- 성능 비교는 입력·모델·버전·하드웨어·예산·평가 지표가 맞는 범위로 한정한다. 논문과 구현의 버전이 다른지 확인한다.
- 핵심 업체/구현 origin을 제외했을 때 남는 독립 실행 또는 재현 기록을 확인한다. 공유 코드/데이터 의존성은 별도로 드러낸다.

`deep-research-tech`/`-tech` 호출은 논문·문헌 경로와 이 경로를 합친다. `deep-research-tech-only`/`-tech-only` 또는 명시적인 단독 technical 요청은 기술 경로만 쓴다. 이 문서는 설치·실행·유료 API·원격 변경 권한을 새로 부여하지 않는다.
