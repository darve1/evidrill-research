# 논문·문헌 조사 — 기본 경로

논문, 학술지, 학회 논문집, 학술서·공인 연구기관의 연구 보고서를 우선한다. 동료심사 여부, 프리프린트, 학위논문, 보고서를 구분한다. 이름난 기관이나 DOI 존재만으로 주장에 지지 판정을 주지 않는다.

질문과 분야에 맞는 학술 검색원·학회/출판사 원문·공개 저장소를 선택한다. 예를 들어 의생명 분야의 PubMed, 컴퓨터과학의 학회 논문집/ACM/IEEE, 공개 논문의 arXiv, 학제적 서지 탐색의 OpenAlex/Crossref 등을 사용 가능한 도구와 접근권 안에서 선택한다. 모든 분야에 같은 데이터베이스 목록을 강제하지 않는다. 검색 도구가 학술 전문 검색을 제공하지 않으면 출판사/학회/연구기관을 좁힌 웹 검색을 사용하고 그 한계를 기록한다.

- 검색 전 포함·제외 범위와 기간을 정한다. 동의어·과거 용어·반대 결과를 찾고 핵심 논문의 참고문헌과 후속 인용을 추적한다. 검색/선별/미확보 이유를 보존한다.
- 원문 표·각주·방법을 읽어 대상, 설계, 표본, 비교군, 데이터셋, 측정법, 효과/불확실성, 계산의 분모를 대조한다. 학문/연구 설계에 맞는 한계를 기록한다. 임상 편향 도구를 모든 분야에 일괄 적용하지 않는다.
- 검색 결과(record), 출판물(report), 실제 연구(study)를 구분한다. 같은 연구의 프리프린트·정식판·해설은 같은 origin이다. 한 논문에 여러 연구가 있으면 근거를 분리해 각 origin에 연결한다. 같은 데이터셋을 쓰는 별개 실험은 서로 다른 origin이며 shared_dependencies로 의존을 드러낸다.
- 정정·철회·후속 재현·실패 결과를 확인한다. 새 결과가 다른 대상/방법에서 나온 경우 단순 승패로 합치지 않는다. 어떤 차이가 충돌을 설명하는지, 설명되지 않는 부분은 무엇인지 적는다.
- 초록만 확보하면 abstract로 남기고 본문·방법·표를 읽었다고 쓰지 않는다. 후보 논문을 찾지 못한 것과 연구 자체가 없는 것을 구분한다.
- 결론 스트레스 테스트에서는 결정적인 연구 origin을 제외해 보고, 좁은 관찰의 지지와 일반화 가능성을 따로 판단한다. 남는 연구 수를 정확도 확률로 바꾸지 않는다.

기본 산출물은 범위를 밝힌 문헌 조사다. 정식 systematic review나 메타분석 요청은 필요한 검색·선별·평가 절차와 미충족 조건을 별도로 명시한다. 학술 검색이 빈약하다고 허락 없이 범용 웹 보고서로 바꾸지 않는다. `-tech`/`-all` 요청은 학술 경로를 유지하면서 다른 경로를 추가한다.
