# Synthetic research corpus

All documents in this folder are fictional fixtures written for this project. Names, journals, identifiers, releases and results do not describe real products or studies. No network retrieval is needed. This folder contains raw inputs, not the expected answer.

Study question: Does the fictional Lumen method outperform Baseline, and is it suitable for adoption now?

Publication identifiers are local fixture IDs, never real DOIs. Read levels refer to the material actually available here. `paper-c-abstract.txt` is only an abstract. The withdrawn full report it mentions is unavailable in this corpus. Each source declares its source route so a bounded invocation can select material without guessing from its filename.
